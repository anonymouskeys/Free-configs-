## How this repository works

1. Private source URLs are read from GitHub Actions secrets and are never published.
2. Subscriptions are downloaded, decoded, parsed and normalized.
3. Duplicate and invalid entries are removed.
4. Clean subscriptions are generated by protocol, transport/security and location.
5. This README and all counters are regenerated from the published output on every successful run.
